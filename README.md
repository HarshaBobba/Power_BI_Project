# Data Professionals Survey Dashboard (Power BI)

**Tools:** Power BI

## Overview
An interactive dashboard analyzing survey responses from data professionals worldwide. It explores how job satisfaction, work-life balance, and compensation vary by country and role, alongside trends in programming language preferences across the field.

## Screenshots
![dashboard](screenshots/dashboard1.png)

## Key Insights
- 630 survey takers, average age 29.87
- Average salary by job title (Data Scientist, Data Engineer, Data Architect, Data Analyst, and more)
- Happiness with work/life balance: 5.74 / 10
- Happiness with salary: 4.27 / 10
- Python is by far the most popular programming language, followed by R and C/C++
- Getting into data is seen as "neither easy nor difficult" by 42.7% of respondents, with 24.76% calling it difficult

## Data Source
Stack Overflow Developer Survey
